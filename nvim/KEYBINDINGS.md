# Keybindings

Generated by `scripts/keybindings.lua` on 2026-11-09. Do not edit by hand; rerun:

```sh
cd ~/.config/nvim && nvim --headless -c 'luafile scripts/keybindings.lua'
```

Leader is **Space**. In Neovim, press `Space` and wait for which-key, or `Space s k` to search all keymaps.

## Markdown files

Only active in `.md` buffers. The LSP keys from the Rust section (`g d`, `K`, `Space c a`, ...) work here too.

|---|---|
| `Space c p` | Markdown Preview |
| `[ [` | Jump to previous section |
| `] ]` | Jump to next section |
| `g O` | Show an Outline of the current buffer _(replaces global: vim.lsp.buf.document_symbol())_ |
